Usage

Push and Pull Images 
# Tag an image for local registry
docker tag my-app:latest 10.1.4.201:58200/my-app:latest

# Push to registry
docker push 10.1.4.201:58200/my-app:latest

# Pull from registry
docker pull 10.1.4.201:58200/my-app:latest

# List repositories
curl -s http://10.1.4.201:58200/v2/_catalog | python3 -m json.tool

# List tags for an image
curl -s http://10.1.4.201:58200/v2/my-app/tags/list | python3 -m json.tool
