Manually trigger a deploy from the latest main branch commit. This will:

  1. Backup current portal files
  2. Clone latest from Forgejo
  3. Sync files to portal directory
  4. Fix permissions (644 for HTML, 755 for dirs)

📚 Beginner Guide (VS Code / Cursor → Git → Deploy)

For developers with no experience (Windows users)

  1. Install VS Code or Cursor on your Windows machine
  2. Install Remote-SSH extension in VS Code/Cursor
  3. Connect via SSH: ssh admin958168@10.1.4.201 -p 52200 (SSH Docker, isolated)
  4. Clone repository: git clone http://10.1.4.201:53000/admin958168/<repo>.git
  5. Edit files in VS Code/Cursor (remote editing via SSH)
  6. Commit & Push: git add . && git commit -m "your changes" && git push
  7. Wait for review: Your push triggers a webhook notification
  8. Admin reviews changes in this Deploy page → selects target → clicks Approve
  9. Deployment runs automatically to the selected Docker container

Important: All commits are mirrored to GitHub automatically. Code review happens in this Portal before deployment.
