⚡ Manual Deploy

Manually trigger a deploy from the latest main branch commit. This will:

  1. Backup current portal files
  2. Clone latest from Forgejo
  3. Sync files to portal directory
  4. Fix permissions (644 for HTML, 755 for dirs)
