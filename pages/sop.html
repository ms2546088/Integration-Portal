📘 Beginner SOP Guide — Start Here

Complete step-by-step guide for users with zero experience. From VS Code/Cursor to production deployment.

Step 1: Install VS Code or Cursor on Your Windows PC
  1. Download VS Code or Cursor
  2. Install the Remote - SSH extension (Microsoft)
  3. Press Ctrl+Shift+P → type "Remote-SSH: Connect to Host"
  4. Enter: admin958168@10.1.4.201 -p 52200 (SSH Docker)
  5. Password: unified password → You are now inside the isolated Docker container

💡 Port 52200 connects to the SSH Docker container (not the host). This is your isolated development environment.

Step 2: Create Your First Project 
# Inside VS Code terminal (connected to SSH Docker):

# Create a project directory
mkdir -p ~/my-project && cd ~/my-project

# Initialize a git repository
git init

# Create your first file
echo '<h1>Hello World!</h1>' > index.html

# Stage and commit
git add .
git commit -m "Initial commit: Hello World"
Step 3: Push to Forgejo (Local Git Server) 
# Add Forgejo as remote origin
git remote add origin http://10.1.4.201:53000/admin958168/my-project.git

# Push your code (use unified credentials when prompted)
git push -u origin main

# Username: admin958168
# Password: (unified password)

Your code is now on Forgejo :53000 — the local Git server.

Step 4: Automatic GitHub Mirror (Setup by Admin)

When admin sets up push mirror for your repo, every push to Forgejo automatically mirrors to GitHub:

Forgejo (:53000) ──push mirror──→ GitHub (jpc202505ms organization)
                 (automatic, within seconds)

Verify on GitHub: jpc202505ms

Step 5: Review and Deploy from Portal
  1. Open Integration Portal :59000
  2. Navigate to Tab 22: Deploy Management
  3. Your push appears in the "Review & Approve" section
  4. Click "Review" → see your changes → select target container
  5. Click "Approve & Deploy" → your code deploys to the selected Docker container
Flow: Your Code → Git Push → Forgejo → Webhook → Auto-deploy
                                              ↓
                               Portal Review → Manual Approve → Target Docker
Step 6: Verify Your Deployment 
# Check your deployed service
curl http://10.1.4.201:YOUR_PORT/

# Check deployment logs
# Portal → Deploy Management → Deploy History

# Check container status
# Portal → Docker Management → Live Container Status
