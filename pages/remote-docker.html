🔧 Method 1: Portainer Agent (Recommended)

On the REMOTE machine (10.1.4.x):

# Install Portainer Agent (one command):
docker run -d -p 9001:9001 --name portainer_agent \
  --restart=always \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /var/lib/docker/volumes:/var/lib/docker/volumes \
  portainer/agent:latest

# Verify:
curl -s http://localhost:9001/ping
# Expected: {"status":"OK"}

On this Portal (10.1.4.201):

  1. Open Portainer :59009
  2. Go to Environments → Add environment
  3. Select Agent, enter URL: 10.1.4.X:9001
  4. Click Connect — remote containers appear immediately
🔌 Method 2: Docker TCP API (No Agent) 
# On the REMOTE machine, expose Docker API:
# Edit /etc/docker/daemon.json:
{
  "hosts": ["unix:///var/run/docker.sock", "tcp://0.0.0.0:2375"]
}

# Restart Docker:
sudo systemctl restart docker

# ⚠️ WARNING: TCP 2375 is UNENCRYPTED. Only use on trusted LAN.

Then add in Portainer: Environments → Docker → tcp://10.1.4.X:2375

Or query directly via API: curl http://10.1.4.201:58192/api/docker/remote/10.1.4.X/2375

🔒 Security Considerations
  • Portainer Agent (port 9001): Encrypted TLS communication, recommended for production
  • Docker TCP (port 2375): Unencrypted, only for trusted 10.1.4.0/24 LAN
  • Docker TLS (port 2376): Encrypted, requires certificate setup on both sides
  • Firewall: ufw allow from 10.1.4.0/24 to any port 9001,2375,2376
  • Unified credentials: All remote hosts use admin958168 / unified password
